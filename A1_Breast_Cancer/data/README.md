# Data — A1: Breast Cancer Diagnosis

## What the dataset is

Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository, dataset id 17.
569 samples × 30 real-valued features (10 nucleus properties × mean / standard error / worst),
target `malignant` (212) vs `benign` (357).

## How to obtain it

No download and no account are needed: the dataset ships with scikit-learn.

```python
from sklearn.datasets import load_breast_cancer

data = load_breast_cancer(as_frame=True)
df   = data.frame                       # 569 x 31 (30 features + 'target')
X    = data.data                        # 569 x 30
y    = 1 - data.target                  # sklearn encodes 0 = malignant; flip to 1 = malignant
```

The notebook does exactly this in cell 2 (`A1_notebook.ipynb`), so the experiment is fully
reproducible offline.

## Verification

* Shape: `X.shape == (569, 30)`, `y.sum() == 212` (malignant), `(1 - y).sum() == 357` (benign).
* `sklearn.datasets.load_breast_cancer()` returns byte-identical data to
  <https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic>
  (identical feature values; the UCI CSV additionally carries an `id` column, which is dropped).

## Why this file is not committed

The data are generated by scikit-learn on demand, so nothing needs to be stored in the
repository. If you export the frame to CSV it will be ignored by `.gitignore` (`*.csv`).
